СРС 4 · Проектирование интеллектуальных систем управления (БПЛА)

Веб-приложение: 7 этапов системы

Приложение моделирует интеллектуальную систему управления беспилотным летательным аппаратом (БПЛА): от сбора данных с камеры и GPS до принятия решений и расчёта вегетационного индекса NDVI. Каждый этап открывается отдельной страницей; переход — кнопками «Далее» и «Назад».

Алгоритмы, которые в проекте обучаются на реальных данных (YOLOv8, CNN–LSTM, PPO), в браузере заменены упрощёнными вычислительными моделями того же назначения. Это указано на каждом этапе.

Этап 1. Подготовка данных и ПО

Источники входных данных

  • Поток данных с камеры — кадры для обнаружения объектов и построения карты.
  • Карта, положение, цель — район полёта, текущие координаты и точка назначения.
  • Данные GPS — широта, долгота, высота; требуют коррекции.

Обработка данных

Сигнал датчика содержит шум, поэтому перед использованием его фильтруют скользящим средним, затем нормализуют в диапазон [0; 1]:

xнорм = (x − xmin) / (xmax − xmin)

Программные средства

Обработка изображений выполняется в OpenCV, коррекция GPS — геодезическим пересчётом (этап 6), коррекция ошибок — фильтрацией и проверкой достоверности значений.

Этап 2. Генерация траектории

Выбираются шаблоны траектории: круговая, восьмёрка или произвольная. Для маршрута в выбранном районе ищется кратчайший путь по сетке с препятствиями (алгоритм поиска в ширину, BFS).

Шаблон траектории

Маршрут по сетке с препятствиями

Район представлен сеткой 20×20 клеток; препятствия расставляются случайно (зерно генератора фиксировано, результат воспроизводим).

Этап 3. Управление полётом

Управление движением в реальном времени: ПИД-регулятор формирует команду скорости по ошибке положения. Коррекция скорости и направления выполняется каждые 0,1 с.

u(t) = Kp·e(t) + Ki·∫e(t)dt + Kd·de/dt

В проекте для обучения управлению можно использовать PPO (обучение с подкреплением); здесь показан классический ПИД-регулятор как базовый вариант.

Этап 4. Обнаружение объектов

Алгоритм работы системы (блок-схема из методических указаний):

Распознавание выполняется нейронной сетью YOLOv8. В браузере её заменяет пороговая сегментация: кадр — синтетическая тепловая карта, объекты — связные яркие области. Для каждого объекта вычисляется центр и приблизительные GPS-координаты.

Этап 5. Создание карты

Картирование среды: по результатам этапов 2 и 4 строится 2D-карта (карта занятости, occupancy grid) с препятствиями, найденным маршрутом и объектами. В проекте для этого используется SLAM; здесь карта строится из уже известных данных.

Этап 6. Изменение координат

GPS задаёт широту и долготу. Для расчёта маршрута их переводят в локальную систему (метры к востоку X и северу Y) относительно опорной точки. При малых расстояниях (до нескольких километров) используется приближение:

X = (λ − λ0)·cos φ0·R,   Y = (φ − φ0)·R,   R ≈ 111 320 м·°⁻¹

Этап 7. Принятие решений и NDVI

Расчёт NDVI

NDVI = (NIR − Red) / (NIR + Red)

Значения NDVI лежат в диапазоне от −1 до 1; здоровая растительность даёт высокие значения, фитостресс — низкие. Решение принимается по порогу: если NDVI < порога, выставляется подозрение на стресс и включается съёмка.

Прогнозирование NDVI (машинное обучение)

По ряду наблюдений за 12 дней строится линейная регрессия NDVI(t) = a + b·t, по ней прогнозируется значение на следующие дни.

Результаты

Прогнозирование, результаты обучения и завершённая карта выведены на этапах 5 и 7 этого приложения. Проверка работы программы сводится к изменению параметров и повторному расчёту на каждом этапе.
